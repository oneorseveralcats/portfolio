# Portfolio

[NixOS Configuration](https://github.com/oneorseveralcats/nixos)

- **Description**: The configuration system I use for all of my computers whether
  they be laptop, desktop, or server. The configuration system has a bunch of of
  modules that define different packages/configurations that are selectively enabled
  via general and device-specific profiles that are imported on those respective devices.

- Declaratively install and configure all programs and services on desktop,
  laptops, and home server using the nix package manager in an infrastructure as
  code manner.

- Repos are pinned to a certain git commit making package versions across devices
  identical and completely reproducible. Can also be used for development
  environments.

- Uses a module system that allows selectively enabling modules depending on
  context with different configurations for desktop, server, and android
  (extensible to WSL2 and MacOS).
